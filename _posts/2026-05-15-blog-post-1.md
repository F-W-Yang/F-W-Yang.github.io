For a Windows11 system, if the file preview function doesn't work in one folder, one can do the following trick:
1. Press 'Shift' + right-click the folder.
2. Open a PowerShell window here.
3. Enter `Get-ChildItem -Recurse -File | Unblock-File` in the command line.
4. Press "enter".
5. Done.
